# z-switch-cli

> 开源无广告的 Claude Code / Codex / Grok 供应商一键切换命令行工具（纯 Rust 原生实现）

## 特性

- **轻量原生**：纯 Rust 构建，单二进制无 GUI/Node 运行时依赖。
- **多客户端支持**：Claude Code、Codex、Grok。
- **直连与本地热切双模式**：
  - **直连模式**：原子化写入客户端原生配置。
  - **本地路由代理模式**：本地轻量代理，支持在终端无需重启的情况下动态热切换供应商。
- **供应商测速与验真**：HTTP 层延迟探测与真实流式 TTFT（首字延迟）测速。
- **生态集成**：支持 Claude Desktop 3p 配置文件与 VS Code 扩展鉴权标记联动。
- **安全备份与自愈**：写入前自动备份、快照恢复、环境自检与修复。
- **一键迁移**：无缝从 `cc-switch`（SQLite / JSON）导入供应商。
